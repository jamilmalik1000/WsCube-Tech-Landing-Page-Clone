# WsCube-Tech-Landing-Page-Clone
A responsive clone of the WsCube Tech landing page built using HTML, CSS (custom styling), and Bootstrap. The project focuses on recreating the layout, structure, and core UI behavior of a modern educational landing page.  Bootstrap is used for grid system and components, while custom CSS handles spacing, typography, and visual refinement.
Key Features

Fully responsive layout using Bootstrap grid

Clean navigation bar with responsive behavior

Accordion component for structured content display

Tab-based content switching

Reusable UI components

Cross-device compatibility (desktop, tablet, mobile)

Purpose

This project is created to:

Practice real-world landing page layout

Improve Bootstrap component usage

Strengthen responsive design fundamentals

Enhance HTML & CSS structuring skills

Tech Stack: HTML, CSS, Bootstrap
